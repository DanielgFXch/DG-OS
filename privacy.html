DG OS · Privacy

Privacy Policy

Effective date: 21 September 2026

DG OS is a personal dashboard and assistant. This policy explains how data is handled when optional third-party integrations, including WHOOP, are connected.

Data we access

DG OS only accesses data that you explicitly authorize. If WHOOP is connected, this can include recovery, physiological cycles and strain, sleep, workouts, profile information and body measurements, depending on the scopes you approve.

How the data is used

Authorized WHOOP data is used only to display and organize your personal health and fitness information inside DG OS, such as sleep, recovery, strain and workout summaries. DG OS does not use WHOOP data for advertising, profiling for third parties or sale.

Authentication and tokens

OAuth client secrets are kept server-side. Access and refresh tokens are not embedded in the public frontend. Where persistent tokens are required, DG OS stores them in the private server environment and protects them with encryption.

Storage and retention

DG OS is designed to request current data from connected services as needed. Integration credentials and refresh tokens may be retained so that the connection continues to work. Any additional cached integration data should be limited to what is necessary for the service to function.

Sharing

DG OS does not sell personal data. Data is not intentionally shared with advertisers or unrelated third parties. Data may pass through infrastructure providers strictly as required to operate the service.

Revoking access and deletion

You can revoke WHOOP access through your WHOOP account or disconnect the integration in DG OS once that control is enabled. To request deletion of DG OS integration credentials or stored integration data, contact the address below.

Security

DG OS uses OAuth for supported integrations and keeps provider secrets outside the public client. No system can guarantee absolute security, but the project is designed to minimize exposed credentials and requested permissions.
